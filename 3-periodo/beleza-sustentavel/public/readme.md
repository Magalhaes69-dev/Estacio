# Beleza Sustentável — Apresentação do Projeto

Bem-vindo ao projeto **Beleza Sustentável**, uma iniciativa dedicada a transformar salões de beleza e barbearias através de práticas de gestão ecoeficientes e sustentáveis.

---

## Pilares do Projeto

O projeto baseia-se em três pilares essenciais de sustentabilidade, integrados para reduzir o impacto ecológico e impulsionar a eficiência financeira e o bem-estar comunitário:

1. **Sustentabilidade Ambiental**
   * **Gestão Sem Papel:** Transição para agendamentos e comandas digitais para eliminar resíduos.
   * **Ecoeficiência:** Redução no consumo de eletricidade (iluminação LED, painéis fotovoltaicos) e água (uso de aeradores e torneiras de baixo fluxo).
   * **Economia Circular:** Destinação inovadora de resíduos, como cabelos cortados para a fabricação de mantas absorventes de óleo ou fertilizantes agrícolas.
   * **Descarte Seguro:** Coleta seletiva e contenção de sobras químicas para evitar contaminação do solo e dos recursos hídricos.

2. **Sustentabilidade Econômica**
   * Redução drástica de desperdício em produtos de consumo diário.
   * Economia financeira gerada pelo uso racional de energia e água.
   * Posicionamento de mercado como uma marca consciente e inovadora, atraindo clientes qualificados.

3. **Sustentabilidade Social**
   * Acolhimento e inclusão social na comunidade local.
   * Valorização e saúde dos colaboradores.
   * Campanhas de conscientização e solidariedade integrada.

## Detalhes de Desenvolvimento Técnico

* **Interface Semântica & Responsiva:** Desenvolvida sob os princípios *Mobile-First* usando Bento Grids e layouts fluidos baseados no framework Tailwind CSS integrado a estilos globais centralizados em [style.css](file:///G:/Meu%20Drive/TI/projetos/beleza_sustentavel/public/style.css).
* **Lógica Vanilla JS:** Todos os comportamentos, menus interativos, modais assíncronos e aberturas programáticas de janelas estão estruturados em [script.js](file:///G:/Meu%20Drive/TI/projetos/beleza_sustentavel/public/script.js).
* **Renderização Dinâmica:** Os tutoriais e este arquivo README são renderizados de maneira 100% dinâmica através da página [tutorial.html](file:///G:/Meu%20Drive/TI/projetos/beleza_sustentavel/public/tutorial.html), usando a biblioteca **Marked.js** via CDN para converter os arquivos de Markdown em HTML.
